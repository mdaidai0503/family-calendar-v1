家族カレンダー v2.4 正式最新版（Excel時刻取込修正版）

修正内容
・「📥Excel取込」を追加
・Excelの必須列は「日付」「予定」
・「開始時刻」「終了時刻」を読み込み、時刻がある予定は自動で終日OFF
・Excel時刻が文字列（17:30）でもExcel時刻値でも読み取り
・同じ日付・同じ予定名の昌輝予定が既にある場合は重複追加せず更新
・カレンダーの予定帯にも開始時刻を表示

今回の昌輝10月予定
・ナイター練習 15件：17:30～20:00 を反映可能

更新手順
1. GitHub等の公開フォルダで index.html / sw.js / manifest.webmanifest をこのZIP内のものに上書き
2. SQLは既にv2.3まで適用済みなら再実行不要
3. iPhoneのPWAを完全に閉じて再起動
4. 「📥Excel取込」から「昌輝_2026年10月_家族カレンダー取込_ナイター時間設定済.xlsx」を選択
5. 取込後、ナイター予定を開き、開始17:30・終了20:00を確認
