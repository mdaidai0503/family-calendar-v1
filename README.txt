家族カレンダー v2.10.1 「＋○件」表示修正版

原因
v2.10では既存の assignLanes() が最大3レーン（0～2）までしか作らず、
4件目以降もlane2へ強制的に重ねていました。
そのため renderBands() の「lane>=4なら＋○件」という条件に到達しませんでした。

修正
・予定数に応じて lane 0,1,2,3,4,5... を正しく割当
・「全員」表示は lane 0～3 の最大4件だけ表示
・lane 4以降は「＋1件」「＋2件」などにまとめて表示
・「＋○件」を押すとその日の予定を全件表示
・一覧から予定編集可能
・JavaScript構文チェック済み
