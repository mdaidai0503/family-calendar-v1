家族カレンダー v2.9 家族共有QR対応

新機能
・設定画面に「📱 家族共有QR」ボタンを追加
・昌史 / 麻美子 / 千晴 / 昌輝 の本人別QRを4つ表示
・本人用QRを読み込むと以下を自動保存
  - Supabase URL
  - Supabase anon key
  - 家族4人の名前
  - この端末の本人
  - 初期表示フィルター
・QRから設定を取り込んだ直後、接続情報をURLから自動削除
・家族側は接続設定を手入力する必要なし

iPhoneでのインストール
1. 本人用QRを標準カメラで読み取る
2. Safariで家族カレンダーを開く
3. 共有ボタン → ホーム画面に追加
4. 次回からホーム画面のアイコンで起動

注意
・iPhoneはWebアプリをQR読取だけで自動インストールできません。
・Supabase anon keyはWebアプリ用の公開クライアントキーですが、QRは家族内だけで共有してください。
・service_role keyは絶対に使用しないでください。
