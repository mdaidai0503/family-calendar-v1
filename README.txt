家族カレンダー v2.3（元予定表参照）

追加機能
・📅月間元予定：表示中の月の月間予定表写真を保存・参照
・📄週間元予定：週間予定表の原本写真を一覧で参照
・📷予定表取込で詳細を反映すると、元の週間写真も自動保存
・元画像はSupabase Storageの非公開バケットに保存
・画像を開くときだけ5分間有効な一時URLを発行

更新手順
1. Supabase SQL Editorで v2.3-source-migration.sql を実行
2. index.html / sw.js / manifest.webmanifest を公開フォルダへ上書き
3. ブラウザ/PWAを再読み込み
4. 9月表示で「📅月間元予定」から月間写真を登録
5. 「📷予定表取込」で週間写真を反映すると、その写真は「📄週間元予定」から参照可能
